## クイックスタート

1. `index.html` をダウンロード
2. ダブルクリックで開く（またはブラウザにドラッグ）
3. 言語を選択（右上のドロップダウン）
4. 「設定を表示」をクリックしてサーバー情報を入力
5. 「サーバーに接続」をクリック

## 機能

- 🌏 12 言語対応のインターフェース
