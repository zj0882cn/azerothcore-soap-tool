## Comienzo rápido

1. Descarga `index.html`
2. Haz doble clic para abrirlo (o arrástralo al navegador)
3. Selecciona el idioma (menú desplegable en la esquina superior derecha)
4. Haz clic en "Mostrar configuración" e ingresa la información del servidor
5. Haz clic en "Conectar servidor"
