## Início rápido

1. Baixe `index.html`
2. Clique duas vezes para abrir (ou arraste para o navegador)
3. Selecione o idioma (menu suspenso no canto superior direito)
4. Clique em "Mostrar configuração" e insira as informações do servidor
5. Clique em "Conectar servidor"
