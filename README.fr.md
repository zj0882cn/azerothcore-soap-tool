## Démarrage rapide

1. Téléchargez `index.html`
2. Double-cliquez pour l'ouvrir (ou faites-le glisser dans le navigateur)
3. Sélectionnez la langue (menu déroulant en haut à droite)
4. Cliquez sur "Afficher la configuration" et entrez les informations du serveur
5. Cliquez sur "Connecter le serveur"
