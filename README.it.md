## Avvio rapido

1. Scarica `index.html`
2. Fai doppio clic per aprirlo (o trascinalo nel browser)
3. Seleziona la lingua (menu a discesa in alto a destra)
4. Clicca su "Mostra configurazione" e inserisci le informazioni del server
5. Clicca su "Connetti server"
