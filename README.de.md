## Schnellstart

1. Lade `index.html` herunter
2. Doppelklicke zum Öffnen (oder in den Browser ziehen)
3. Sprache auswählen (Dropdown oben rechts)
4. Klicke auf "Konfiguration anzeigen" und gib Serverinformationen ein
5. Klicke auf "Server verbinden"

---

## Funktionen

- 🌏 12-sprachige Oberfläche
