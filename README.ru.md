## Быстрый старт

1. Скачайте `index.html`
2. Дважды щелкните для открытия (или перетащите в браузер)
3. Выберите язык (выпадающее меню в правом верхнем углу)
4. Нажмите «Показать конфигурацию» и введите информацию о сервере
5. Нажмите «Подключить сервер»
